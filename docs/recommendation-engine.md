# Recommendation Engine

## First Version

Use rule-based recommendation plus weighted preference.

Inputs:

- Current user state
- State analysis scores
- Sleep history
- Previous feedback
- Sound preference weights
- Current time

Outputs:

- Sound Profile
- Session template
- Voice guide strategy
- Master volume curve

## Upgrade Path

Keep the recommendation interface stable so that a future machine learning model can replace the internal scoring logic without changing the product flow.
