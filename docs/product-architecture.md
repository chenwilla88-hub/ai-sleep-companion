# Product Architecture

## Core Loop

User State Input -> AI State Understanding -> Sound Profile -> Dynamic Sound Mix -> Sleep Session -> Morning Feedback -> Personal Sleep Profile.

## MVP Principle

The first version should complete the core loop before adding community, social features, complex membership, wearable integrations, or medical claims.

## Main Product Path

1. Home
2. AI Sleep Coach
3. Sleep State Analysis
4. AI Sound Recommendation
5. Sleep Session
6. Morning Feedback
7. Sleep Profile Update

## Modules

- Frontend: page structure, interaction, playback controls
- AI Service: user state analysis and concise sleep companion copy
- Recommendation Engine: rule-based recommendation plus weighted preference
- Audio Engine: Web Audio API mixing and timeline playback
- Sleep Profile Service: preference learning from feedback
- Database: sessions, profiles, assets, mixes, and conversations
